# AuditCore v1.0.0

**Fecha:** 2026-08-11  
**Estado:** Estable

AuditCore v1.0.0 representa el cierre de la reconstrucción y evolución profesional del proyecto académico de Auditoría Informática del ITLA hacia una plataforma full stack para gestión de auditorías de TI.

## Principales capacidades

- Gestión completa de auditorías y su ciclo de vida.
- Riesgos, hallazgos, evidencias y planes de acción.
- Marcos, controles, preguntas, evaluaciones y respuestas.
- Organizaciones, sucursales, departamentos, usuarios, roles y permisos.
- Dashboard ejecutivo y reportes CSV, XLSX y PDF.
- Autenticación JWT, refresh tokens rotativos y RBAC.
- Aislamiento multiempresa.
- Frontend React 19 + TypeScript 6 integrado con la API.
- Backend .NET 10 + EF Core + SQL Server.
- Docker Compose para ejecución full stack.

## Calidad y seguridad

La versión fue cerrada únicamente después de validar en GitHub Actions:

- Backend CI ✅
- Frontend CI ✅
- E2E CI ✅
- Security CI ✅
- Container CI ✅

El backend mantiene 57 pruebas automatizadas y la suite E2E valida un flujo integral desde autenticación hasta generación de reportes usando la aplicación y la base de datos reales.

Durante el hardening se incorporaron auditorías de dependencias NuGet/npm y se corrigió la dependencia de React Router afectada por una alerta de seguridad.

## Infraestructura

La solución incluye imágenes Docker independientes para API y frontend, Nginx para servir la SPA, SQL Server mediante Docker Compose y persistencia por volúmenes tanto para la base de datos como para evidencias.

## Nota académica

AuditCore tiene su origen conceptual en la asignatura **Auditoría Informática (SOF-009)** del Instituto Tecnológico de Las Américas (ITLA), período **2017-C2**, y fue reconstruido posteriormente como proyecto de portafolio con estándares modernos de ingeniería de software.
